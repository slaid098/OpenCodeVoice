# ADR 0014: model list without native datalist

- **Date**: 2026-10-23

## Статус

Accepted.

## Контекст

Кнопка «Загрузить модели» в настройках загружала список через `/models` или `/api/tags` и складывала его в нативный `<datalist>`, связанный с полем модели атрибутом `list`. Загрузка работала, статус показывал «Модели загружены: N», но выбрать модель было нельзя.

Причины:

- Firefox for Android не показывает datalist для текстовых полей (баг Mozilla 1535985, caniuse: not supported);
- Firefox desktop открывает подсказки только после ввода или нажатия ↓, а не по клику/фокусу;
- Chrome/Edge показывают список только при фокусе/клике по полю — сам после программной загрузки он не открывается;
- панель настроек живёт в Shadow DOM, где поведение нативного datalist дополнительно зависит от браузера.

## Решение

**1. Собственный inline-listbox.** `addModelInput` в `settings-panel.ts` создаёт под полем блок `.model-list` (`role="listbox"`) с вариантами `.model-option` (`role="option"`). Список находится внутри `.field`, поэтому скролл `.content` его не обрезает, не нужны fixed-координаты и пересчёт при прокрутке.

**2. Поведение.** После успешной загрузки список открывается сам и показывает все модели. Клик по полю открывает список, ввод фильтрует по подстроке, клик по варианту подставляет ID в поле и draft. Пустой результат фильтра показывает строку «Нет совпадений». Поле остаётся свободным для произвольного ID, поэтому прокси и нестандартные модели работают как раньше.

**3. Клавиатура и закрытие.** ↑/↓ перемещают подсветку, Enter выбирает, Escape закрывает только список, Tab закрывает список и передаёт фокус дальше. Панель перехватывает Escape в capture-фазе на `document`, поэтому её обработчик сначала вызывает `closeActiveModelList()` и только потом закрывает шторку. Список также закрывается при выборе, клике вне поля/списка, смене вкладки/провайдера и закрытии панели.

**4. Доступность.** Поле помечено `role="combobox"`, `aria-expanded`, `aria-controls`, `aria-autocomplete="list"`; активный вариант передаётся через `aria-activedescendant`, текущее значение — через `aria-selected`.

## Последствия

- Список моделей работает на Firefox Android, Firefox desktop и Chromium, в том числе внутри Shadow DOM.
- Нативный `<datalist>` и `fillDatalist` удалены; новый ключ i18n `settings.models.noMatches` есть в RU и EN.
- Список открывается автоматически после загрузки, поэтому кнопка «Загрузить модели» даёт ожидаемый результат без дополнительного клика по полю.
- Inline-список сдвигает поля ниже; это осознанный компромисс ради надёжности на мобильных.
